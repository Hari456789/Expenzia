Expenzia is a Flutter-based expense-tracking application designed to help users manage their daily transactions, track income and expenses, and view their transaction history through a simple, user-friendly interface.

Features

Dashboard: Overview of income and expenses.

Transaction Management: Add and edit transactions.

Transaction History: View previous transactions.

Swipe Actions: Edit or delete transactions easily.

Date Selection: Select transaction dates.

Profile Screen: View and manage profile details.

Clean UI: Simple interface with a consistent theme.

Built With

Flutter

Dart

Material Design
